# 手持弹幕工程代码解析文档（v2.0 更新版）

> **更新日期**：2026-06-22  
> **更新内容**：HarmonyOS SDK 6.0(20) API 适配 + 大小屏自适应增强 + 弹幕颜色调色板 + 科幻风格 UI 美化 + 阴影效果 + 异常处理完善

---

## 一、项目概述

本工程是基于 HarmonyOS ArkTS 的手持弹幕应用，在原有弹幕功能基础上新增了 12 项扩展功能及自由流转、一次开发多端部署能力。采用 `@ComponentV2` + `Navigation` 架构，使用 `NavPathStack` 进行页面路由管理，通过 HarmonyOS 分布式能力实现跨设备自由流转。

## 三、数据模型详解

### 3.1 Settings.ets — 弹幕设置数据模型

**文件路径**: `model/Settings.ets`

```typescript
export enum DisplayArea {
  TOP = 'top',      // 上方显示
  CENTER = 'center', // 居中显示
  BOTTOM = 'bottom'  // 下方显示
}

export enum DisplayMode {
  SLIDE = 'slide',   // 滑动弹幕（从右往左滚动）
  STATIC = 'static'  // 滞留弹幕（静止显示在屏幕上）
}

export class Settings {
  content: string = '';                           // 弹幕文本内容
  fontSize: number = 0;                           // 字体大小（88/168/248）
  fontWeight: FontWeight = FontWeight.Regular;    // 字体粗细
  fontColor: string = '#FFFFFF';                  // 弹幕文字颜色，HEX格式
  speed: number = 6;                              // 滚动速度 1-12
  displayArea: DisplayArea = DisplayArea.CENTER;  // 显示区域
  displayMode: DisplayMode = DisplayMode.SLIDE;   // 显示方式
  bgColor: string[] = ['#013C9C', '#3066E4', '#43A1F4']; // 背景渐变色
  themeName: string = '默认蓝';                    // 主题名称
}
```

**构造函数设计**: 所有扩展字段均为可选参数，通过 `undefined` 判断默认值，保持向后兼容。

#### 流转序列化/反序列化

- **`toRecord(): SettingsRecord`** — 将 Settings 实例转为可序列化接口，`fontWeight` 枚举→数值
- **`static fromRecord(record: SettingsRecord): Settings`** — 反序列化恢复，数值→枚举映射（ArkTS 不支持计算属性名，使用 if-else 判断）

## 五、页面详解

### 5.1 Index.ets — 弹幕设置首页（v2.0 重大更新）

**装饰器**: `@Entry` + `@ComponentV2`

#### 5.1.1 新增：16 色调色板常量

```typescript
const DANMAKU_COLORS: string[] = [
  '#FFFFFF', '#FFF176', '#FFD740', '#FFB74D',
  '#FF8A80', '#FF5252', '#F48FB1', '#E040FB',
  '#7C4DFF', '#448AFF', '#40C4FF', '#80D8FF',
  '#64FFDA', '#69F0AE', '#B2FF59', '#FF6E40'
];
```

覆盖白/黄/橙/红/粉/紫/蓝/青/绿 16 色。

#### 5.1.2 新增：选色交互设计

```typescript
@Local selectedColorIndex: number = 0;
```

| 操作 | 行为 |
|------|------|
| 点击色块 | `fontColor = color; selectedColorIndex = index` |
| 选中反馈 | 蓝色 3px 边框 + 阴影半径 6 |
| 未选中 | 灰色 1px 细边 + 阴影半径 2 |
| 输入自定义 Hex | `selectedColorIndex = -1`（取消调色板选中） |
| 切换主题 | `selectedColorIndex = DANMAKU_COLORS.indexOf(theme.defaultFontColor)` |

色块大小：sm=36x36，md/lg=40x40。下方保留 Hex 输入框（placeholder="#自定义颜色"）。

#### 5.1.3 新增：断点自适应方法

| 方法 | sm | md | lg | 用途 |
|------|:--:|:--:|:--:|------|
| `titleFontSize()` | 26 | 30 | 34 | 页面标题 |
| `sectionLabelFontSize()` | 14 | 15 | 16 | 分区标签 |
| `settingLabelFontSize()` | 16 | 17 | 18 | 设置项标签 |
| `btnHeight()` | 44 | 48 | 48 | 按钮最小高度 |
| `previewHeight()` | 199 | 280 | 360 | 预览区高度 |

按钮高度符合 HarmonyOS 48vp 最小触控目标推荐标准。

#### 5.1.4 科幻 UI 设计系统

| 元素 | 颜色值 |
|------|--------|
| 页面背景 | `#E8EDF2`（浅蓝灰） |
| 卡片背景 | `Color.White` + `rgba(0,0,0,0.06)` 边 |
| 标题文字 | `#1A1C1E` + `rgba(30,111,255,0.15)` 辉光 |
| 辅助文字 | `#5F6368` / `#3C4043` |
| 主按钮 "显示弹幕" | `#0A59F7` + `rgba(10,89,247,0.35)` 辉光 |
| 功能按钮 | `rgba(0,0,0,0.04)` 底 + `rgba(0,0,0,0.08)` 边 |
| 输入框 | `Color.White` + `rgba(0,0,0,0.08)` 边 |
| Select 下拉 | `Color.White` 底 + `#5F6368` 字 |
| 滑块 | `#5F6368` 把手 + `rgba(0,0,0,0.06)` 轨 |

#### 5.1.5 API 适配变更

- `getContext(this)` → `this.getUIContext().getHostContext()`（SDK20 弃用）
- `import { Context }` → `import { common }`，类型用 `common.Context`
- GridRow 断点语法：`{ reference: BreakpointsReference.WindowSize, breakpointSystem: [...] }` → `{ value: ['600vp', '840vp'] }`
- `onBreakpointChange` 从 GridRow 构造参数移出，改链式调用 `.onBreakpointChange((bp) => {...})`

#### 5.1.6 预览区阴影增强

预览区弹幕文字增加 `.shadow({ radius: 4, color: 'rgba(0,0,0,0.4)', offsetX: 1, offsetY: 1 })`

### 5.2 Led.ets — 弹幕展示页（v2.0 增强）

**装饰器**: `@ComponentV2`

#### 5.2.1 新增：动态阴影

```typescript
private getShadowRadius(): number {
  if (this.screenWidth >= 1200) return 16;  // 超大屏
  if (this.screenWidth >= 840) return 12;   // 大屏
  return 8;                                  // 手机
}
```

滑动/滞留两种模式的 Text 均添加：
```typescript
.shadow({ radius: this.getShadowRadius(), color: 'rgba(0,0,0,0.5)', offsetX: 2, offsetY: 2 })
```

#### 5.2.2 API 适配变更

- 移除 `context.windowStage`（SDK20 中该属性已从 `NavDestinationContext` 移除）
- 改用 `.onAreaChange()` 获取屏幕宽度（返回值已是 vp，无需 `px2vp`）
- `import { window }` 仅保留 `window.Orientation` 枚举引用

#### 5.2.3 自适应保留

- **字号自适应**：`getAdaptiveFontSize()`，基准 800vp，最大 2x
- **方向自适应**：`getPreferredOrientation()`，≥840vp → UNSPECIFIED，否则 LANDSCAPE

## 十六、自由流转功能

**配置**: `module.json5` → `"continuable": true`

**流转链路**:
```
设备A: 发送弹幕 → Settings → toRecord() → JSON → AppStorage
   ↓ 用户触发流转
onSaveData(params) → 跨设备传输
   ↓
设备B: onRestoreData → AppStorage → JSON.parse → fromRecord()
   ↓
Index.ets restoreFromContinue() → 延迟300ms → pushPathByName('Led')
```
