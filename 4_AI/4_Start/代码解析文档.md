# 手持弹幕工程代码解析文档

## 一、项目概述

本工程是基于 HarmonyOS ArkTS 的手持弹幕应用，在原有弹幕功能基础上新增了 8 项扩展功能。采用 `@ComponentV2` + `Navigation` 架构，使用 `NavPathStack` 进行页面路由管理。

---

## 三、数据模型详解

### 3.1 Settings.ets — 弹幕设置数据模型

**文件路径**: `model/Settings.ets`

```typescript
export enum DisplayArea {
  TOP = 'top',      // 上方显示
  CENTER = 'center', // 居中显示
  BOTTOM = 'bottom'  // 下方显示
}

export class Settings {
  content: string = '';                          // 弹幕文本内容
  fontSize: number = 0;                          // 字体大小（88/168/248）
  fontWeight: FontWeight = FontWeight.Regular;   // 字体粗细
  fontColor: string = '#FFFFFF';                 // 弹幕文字颜色（新增）
  speed: number = 6;                             // 滚动速度 1-12（新增）
  displayArea: DisplayArea = DisplayArea.CENTER;  // 显示区域（新增）
  bgColor: string[] = ['#013C9C', '#3066E4', '#43A1F4']; // 背景渐变色（新增）
  themeName: string = '默认蓝';                   // 主题名称（新增）
}
```

**字段说明**:

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `content` | string | '' | 弹幕文本内容 |
| `fontSize` | number | 0 | 字体大小，三档：88(小)/168(中)/248(大) |
| `fontWeight` | FontWeight | Regular | 字体粗细：Regular/Medium/Bold |
| `fontColor` | string | '#FFFFFF' | 弹幕文字颜色，支持 HEX 格式 |
| `speed` | number | 6 | 跑马灯滚动步长，1=最慢，12=最快 |
| `displayArea` | DisplayArea | CENTER | 弹幕在屏幕的垂直位置 |
| `bgColor` | string[] | 蓝色渐变 | 背景渐变色数组 [起始色, 中间色, 结束色] |
| `themeName` | string | '默认蓝' | 当前主题名称，用于主题切换联动 |

**构造函数设计**: 新增字段均为可选参数（`fontColor?`, `speed?` 等），通过 `undefined` 判断赋值，**保持向后兼容**，原有的三参数调用方式不受影响。

### 4.1 ThemeManager.ets — 主题管理器

**文件路径**: `utils/ThemeManager.ets`

**核心接口**:
```typescript
export interface ThemeConfig {
  name: string;            // 主题名称
  bgColors: string[];     // 背景渐变色 [色1, 色2, 色3]
  defaultFontColor: string; // 该主题默认文字颜色
}
```

**内置 8 套主题**:

| 主题名 | 背景色 | 文字色 | 风格描述 |
|--------|--------|--------|---------|
| 默认蓝 | #013C9C → #3066E4 → #43A1F4 | #FFFFFF | 经典蓝色渐变 |
| 暗夜黑 | #1A1A2E → #16213E → #0F3460 | #E0E0E0 | 深色护眼模式 |
| 烈焰红 | #8B0000 → #C62828 → #E53935 | #FFFFFF | 热烈红色渐变 |
| 翡翠绿 | #1B5E20 → #2E7D32 → #43A047 | #FFFFFF | 清新绿色渐变 |
| 暮光紫 | #4A148C → #6A1B9A → #8E24AA | #FFFFFF | 神秘紫色渐变 |
| 极简白 | #F5F5F5 → #E0E0E0 → #BDBDBD | #212121 | 亮色极简模式 |
| 赛博霓虹 | #0D0221 → #150734 → #1A0A3E | #00FFFF | 赛博朋克风 |
| 日落橙 | #E65100 → #F57C00 → #FF9800 | #FFFFFF | 温暖橙色渐变 |

**API 方法**:
- `static getThemeByName(name: string): ThemeConfig` — 按名称获取主题配置，找不到则返回默认蓝
- `static getAllThemeNames(): string[]` — 获取所有主题名称数组

**联动逻辑**: 切换主题时，会自动将 `fontColor` 更新为主题默认文字色，确保文字与背景的对比度。

### 4.3 KeywordFilter.ets — 关键词过滤器

**文件路径**: `utils/KeywordFilter.ets`

**持久化方式**: 使用 `@kit.ArkData` 的 `preferences` API，存储名称 `danmu_keyword`，键名 `filter_keywords`。

**核心逻辑**:
- **添加关键词**: `addKeyword(keyword)` — 去重添加，自动持久化
- **删除关键词**: `removeKeyword(keyword)` — 移除并持久化
- **过滤内容**: `filterContent(content)` — 将匹配到的关键词替换为等长度的 `*` 号
- **检测关键词**: `containsKeyword(content)` — 判断内容是否包含过滤词

**过滤示例**: 关键词列表含"垃圾"，弹幕内容"这个真垃圾" → 过滤后"这个真**"

### 4.4 HistoryManager.ets — 历史记录管理器

**文件路径**: `utils/HistoryManager.ets`

**持久化方式**: `preferences`，存储名称 `danmu_history`，键名 `history_list`。

**核心接口**:
```typescript
export interface HistoryItem {
  content: string;    // 弹幕内容
  timestamp: number;  // 发送时间戳
  fontColor: string;  // 使用的颜色
}
```

**核心逻辑**:
- **添加记录**: `addHistory(item)` — 新记录插入数组头部（最新在前），上限 100 条，超出自动裁剪
- **获取记录**: `getHistory()` — 返回全部历史记录
- **清空记录**: `clearHistory()` — 清空所有历史

### 4.5 StatsManager.ets — 统计数据管理器

**文件路径**: `utils/StatsManager.ets`

**持久化方式**: `preferences`，存储名称 `danmu_stats`，键名 `daily_stats`。

**核心接口**:
```typescript
export interface DailyStat {
  date: string;   // 日期字符串，格式 YYYY-MM-DD
  count: number;  // 当日发送数量
}
```

**核心逻辑**:
- **记录发送**: `recordSend()` — 当天计数+1，如当天无记录则新建；最多保留 30 天数据
- **获取统计**: `getDailyStats()` — 返回每日统计列表
- **总发送量**: `getTotalCount()` — 所有天数的发送量之和
- **日均发送**: `getAvgPerDay()` — 总量÷天数，四舍五入取整

## 五、页面详解

### 5.1 Index.ets — 弹幕设置首页

**文件路径**: `pages/Index.ets`

**装饰器**: `@Entry` + `@ComponentV2`

#### 状态变量一览

| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `content` | string | '欢迎学习鸿蒙开发' | 弹幕文本 |
| `fontSize` | number | 88 | 字体大小 |
| `fontSizeFlag` | string | '小' | 字号标签 |
| `fontWeight` | FontWeight | Regular | 字体粗细 |
| `selectedIndex` | number | 0 | 粗细选中索引 |
| `fontColor` | string | '#FFFFFF' | 弹幕文字颜色 |
| `speed` | number | 6 | 滚动速度 |
| `speedFlag` | string | '中' | 速度标签 |
| `displayArea` | DisplayArea | CENTER | 显示区域 |
| `displayAreaIndex` | number | 1 | 区域选中索引 |
| `themeName` | string | '默认蓝' | 当前主题 |
| `themeIndex` | number | 0 | 主题选中索引 |
| `filterKeyword` | string | '' | 正在输入的过滤词 |
| `showPresetPanel` | boolean | false | 预设模板面板是否展开 |
| `showKeywordPanel` | boolean | false | 关键词过滤面板是否展开 |
| `keywordList` | string[] | [] | 已添加的过滤关键词列表 |
| `isManagersReady` | boolean | false | 管理器是否初始化完成 |

#### 页面布局结构

```
Navigation(NavPathStack)
└── Column
    ├── 标题区: "手持弹幕"
    ├── 预览区
    │   ├── 标题 "预览"
    │   └── 弹幕预览框（渐变背景 + 跑马灯文字）
    └── Scroll 可滚动区域
        ├── 弹幕内容输入区（TextArea）
        ├── 功能按钮行
        │   ├── 预设模板（展开/折叠）
        │   ├── 关键词过滤（展开/折叠）
        │   ├── 历史记录（跳转 HistoryPage）
        │   └── 统计面板（跳转 StatsPage）
        ├── 预设模板面板（条件渲染 showPresetPanel）
        ├── 关键词过滤面板（条件渲染 showKeywordPanel）
        ├── 显示设置区
        │   ├── 字体大小 Slider（88-248，步长80）
        │   ├── 字体粗细 Select（Regular/Medium/Bold）
        │   ├── 弹幕速度 Slider（1-12，步长1）
        │   ├── 弹幕颜色（颜色预览圆 + HEX 输入框）
        │   ├── 显示区域 Select（上方/居中/下方）
        │   └── 弹幕主题 Select（8套主题）
        └── "显示弹幕" 按钮
```

#### 核心方法逻辑

**`initManagers(context)`** — 页面加载时异步初始化三个持久化管理器，使用 `Promise.all` 并行初始化，初始化完成后加载已有关键词列表。

**`onSendDanmu()`** — 发送弹幕核心流程：
1. 获取弹幕内容
2. 如有关键词过滤规则，调用 `keywordFilter.filterContent()` 进行替换
3. 封装 `Settings` 对象（包含所有新旧配置项）
4. 异步保存历史记录和统计数据
5. 跳转到弹幕展示页 `Led`

**`handleThemeChange(index)`** — 主题切换时同步更新字体颜色为主题默认色，避免文字与背景不可见。

**`handleSpeedChange(value)`** — 速度值到标签的映射：≤3="慢"，4-8="中"，≥9="快"。

**`applyPreset(template)`** — 一键应用预设模板，将模板内容填入输入框并收起面板。

### 5.2 Led.ets — 弹幕展示页

**文件路径**: `pages/Led.ets`

**装饰器**: `@ComponentV2`

#### 核心功能

- **全屏横屏展示**: `preferredOrientation(window.Orientation.LANDSCAPE)`
- **跑马灯滚动**: `TextOverflow.MARQUEE` + `marqueeOptions({ start: true, step: speed })`
- **文字颜色**: 使用 `settings.fontColor` 替代硬编码白色
- **滚动速度**: 通过 `marqueeOptions.step` 控制步长
- **显示区域**: 通过 `getContentAlign()` 将 `DisplayArea` 映射为 `FlexAlign`
  - TOP → `FlexAlign.Start`（上方）
  - CENTER → `FlexAlign.Center`（居中）
  - BOTTOM → `FlexAlign.End`（下方）
- **背景渐变**: 使用 `settings.bgColor` 数组动态渲染
- **AI 播报**: 右上角菜单按钮，调用 `Speaker.startSpeak()`
- **返回按钮**: 左上角 `chevron_left` 图标

#### 数据接收

```typescript
.onReady((context: NavDestinationContext) => {
  this.settings = context.pathInfo.param as Settings;
})
```

通过 `NavDestination.onReady` 回调接收 Index 页传递的 `Settings` 对象。

### 5.4 StatsPage.ets — 弹幕统计面板页

**文件路径**: `pages/StatsPage.ets`

**装饰器**: `@ComponentV2`

#### 页面结构

```
NavDestination（标题：弹幕统计面板）
└── Column
    ├── 加载中状态
    └── 数据内容
        ├── 统计概览卡片（Row 三列均分）
        │   ├── 总发送量（蓝色大字）
        │   ├── 日均发送（浅蓝大字）
        │   └── 记录天数（绿色大字）
        └── 每日发送统计图表卡片
            ├── 标题 "每日发送统计"
            └── 水平滚动柱状图
                └── Row（底部对齐）
                    └── Column × N（每日一根柱子）
                        ├── 蓝色柱体（高度 = count/maxCount × 160）
                        ├── 数量标签
                        └── 日期标签（MM-DD 格式）
```

#### 柱状图实现原理

采用**纯 ArkUI 布局**实现，无需第三方图表库：
- 每根柱子是一个 `Column` 组件，宽度固定 24px
- 柱子高度按比例计算：`Math.max(4, (count / maxCount) * 160)`
- 最大值柱子占满 160px 高度，其他按比例缩放
- 最小高度 4px 避免为 0 时不可见
- 水平方向使用 `Scroll + Row` 支持横向滚动
- 底部对齐 `alignItems(VerticalAlign.Bottom)`

## 九、持久化存储设计

| 管理器 | preferences 名称 | 键名 | 数据格式 | 上限 |
|--------|-----------------|------|---------|------|
| HistoryManager | `danmu_history` | `history_list` | `HistoryItem[]` JSON | 100 条 |
| StatsManager | `danmu_stats` | `daily_stats` | `DailyStat[]` JSON | 30 天 |
| KeywordFilter | `danmu_keyword` | `filter_keywords` | `string[]` JSON | 无限制 |

所有持久化均使用 HarmonyOS `@kit.ArkData` 的 `preferences` 轻量级键值对存储，适合小数据量的场景。写入后均调用 `flush()` 确保数据落盘。
