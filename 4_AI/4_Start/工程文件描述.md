# 工程文件结构说明

## 一、工程概述
本项目是一个基于HarmonyOS开发的手持弹幕应用，使用ArkTS语言开发，核心功能是在手机/平板/2in1设备上编辑并全屏展示弹幕文字，支持滑动弹幕和滞留弹幕两种显示方式。

## 二、整体目录结构

```
4_Start/                              # 起步工程（基础弹幕功能）
4_Complete/                           # 完成工程（10项扩展功能）
├── AppScope/                         # 应用全局配置
├── entry/                            # 主模块
│   ├── src/main/ets/                 # ArkTS 源代码
│   │   ├── entryability/             # 应用入口Ability
│   │   ├── model/                    # 数据模型
│   │   ├── pages/                    # 页面
│   │   └── utils/                    # 工具类
│   └── src/main/resources/           # 静态资源
└── hvigor/                           # 构建配置
```

## 三、4_Start 与 4_Complete 区别

| 对比项 | 4_Start | 4_Complete |
|--------|---------|------------|
| 基础弹幕功能 | 有 | 有 |
| 弹幕颜色自定义 | 无 | 有 |
| 弹幕速度调节 | 无 | 有 |
| 弹幕历史记录 | 无 | 有 |
| 弹幕统计面板 | 无 | 有 |
| 关键词过滤 | 无 | 有 |
| 预设模板库 | 无 | 有 |
| 弹幕主题切换 | 无 | 有 |
| 弹幕显示区域 | 无 | 有 |
| 自由流转 | 无 | 有 |
| 弹幕显示方式（滑动/滞留） | 无 | 有 |
| 多端设备支持 | 仅phone | phone/tablet/2in1 |
